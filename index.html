Pilih Puskesmas Anda
Setiap Puskesmas memiliki data antrean sendiri-sendiri (nomor tiket, loket, riwayat).
Silakan pilih Puskesmas terlebih dahulu.
Pilihan ini dapat diubah kembali nanti melalui menu Pengaturan → Profil Puskesmas.
Menghubungkan ke Supabase
Aplikasi ini menyimpan data secara online di Supabase, sehingga seluruh perangkat (kiosk, papan tampilan, admin) bisa saling sinkron dari mana saja lewat internet — tidak perlu berada di jaringan Wi-Fi/LAN yang sama.
URL dan Anon Key wajib diisi.
Ambil kedua nilai ini dari dashboard Supabase project Anda: Project Settings → API. Pastikan skema tabel & fungsi SQL sudah dijalankan lebih dulu di SQL Editor (lihat berkas supabase-schema.sql).
